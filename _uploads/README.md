# Upload intake

Place PDFs, Markdown files, and plain-text files directly in this folder. Use a clear prefix so each file's purpose is immediately visible:

- `cv-` for a CV PDF or CV source text.
- `abstract-` for a paper abstract.
- `note-` for study notes and their descriptions.
- `writing-` for biographies, project descriptions, or other website copy.

Examples: `cv-maharnab-naha.pdf`, `abstract-status-incentives.md`, and `note-econometrics-panel-data.pdf`.

Files placed here are ignored by Git and are not published automatically. This prevents drafts or private material from becoming public by accident.

When material is ready, ask Codex to update the website from `_uploads`. Approved public downloads will be moved into `assets/`, linked from the appropriate page, and checked before publication.
